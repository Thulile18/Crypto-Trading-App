# Crypto Trading App– React Native UI Challenge

A crypto exchange screen built with React Native and Expo, based on the Crypto Trading App design by Bogdan Nikitin (Nixtio) on Dribbble.

## Download
Android APK: https://drive.google.com/file/d/1pVLJSAgOsuQyhH1B5duXJTTB5lT6h1ws/view?usp=drivesdk

## Features
- Type an amount in either box and the other updates automatically
- Swap button flips the currencies (Buy ETH / Sell ETH)
- Balance check with an error message
- Fee, amount received, spread and gas fee update with the amount
- Buttons change colour when pressed or hovered
- Responsive: text size and layout adjust to the screen width

## Components
- Header
- IconButton (used twice)
- CurrencyRow (used twice)
- CoinIcon (used twice)
- EthLogo
- SwapDivider
- ActionButton
- DetailRow (used four times)

## Run it
cd exchange-native
npm install
npx expo start

## Built with
React Native, Expo, StyleSheet, expo-linear-gradient, react-native-svg
